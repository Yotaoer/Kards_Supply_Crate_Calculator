# 规则与计算口径

> 原代码假设属于历史证据。当前合同见“重写版计算合同”及集中规则 `src/rules.ts`，不继承旧版锁定交互。

## 来源与基线

- 原代码来自 `https://github.com/Yotaoer/Kards_Supply_Crate_Calculator` 的提交 `6a866e08929fee7dc427a016f383455cd7dc0777`，当时仓库仅有 README.md 和 index.html。
- 表格来源为作者提供的计算表截图，未随源码发布；不视为游戏官方规则或当前版本的实测证明。

## 图片给定

| 项目 | 数值 |
| --- | --- |
| 四段升级所需进度 | 20 / 30 / 50 / 100 |
| 仅开包进度 | 普通包 3；军官包 6 |
| 重复金 / 银 / 铜 / 铁卡进度 | 24 / 8 / 2.4 / 0.8 |
| 全卡情境每包进度 | 普通 13.688；军官 29.936 |
| 全铜铁情境每包进度 | 普通 9.448；军官 14.976 |
| 0卡情境每包进度 | 普通 3；军官 6 |

图片军官“预计出卡数量”为金 0.48、银 1.18、铜 2.94、铁 2.40。普通为 0.09、0.26、1.70、2.96，显示精度有限。
图片还有概率、保底及等额军官包等行，但不足以单独证明抽卡独立性、完整保底规则或当前游戏版本机制。

## 原代码假设

- 等级依次为基础、普通、限定、特殊、精英；上述四段进度逐段累加，总计200。
- 普通包100金币、军官包330金币。包价来自源码，不作为图片外新增的官方事实。
- 未开全卡开关时只计算开包3/6点，不估计部分收集度产生的重复卡收益。
- 全卡开关用13.688/29.936替换3/6，**没有另加开包基础进度**。
- 销毁输入为用户计划销毁的数量，不是库存；金币输出为方案开销，不是余额校验。自动配方不产生销毁建议，也不限制金币或库存。
- 锁定表示自动计算和配方按钮不得改该来源；用户仍可手动编辑。自动计算保留最近手动修改的来源，优先补普通包，其次军官包；减包优先军官包。

## 可复核推导

- 军官：`0.48*24 + 1.18*8 + 2.94*2.4 + 2.40*0.8 = 29.936`。
- 如另加仅开包6点则为35.936。图片与旧代码不足以判定应否相加，重写版保留29.936。
- 普通用图片显示张数加权得 `0.09*24 + 0.26*8 + 1.70*2.4 + 2.96*0.8 = 10.688`；另加3得13.688。张数已四舍五入，算式吻合不证明其为精确概率推导，更不能据此解释军官口径。
- 期望收益不是最低收益。`ceil(需求/期望收益)` 只使模型期望达到需求，不代表实际开包保底达标。

## 待确认

全卡系数是否已包含开包基础点数、普通与军官口径为何不同；普通精确预计张数和完整概率推导；保底规则、重复卡转换条件及上述经验/价格在游戏现行版本是否仍成立。确认前不擅改数值，不宣称保底或资源最优。

## 重写版计算合同

- 保留上述规则证据，不新增游戏规则。
- `src/rules.ts` 集中配置阶梯、开包与重复卡经验、包价；`src/calculator.ts` 是独立纯计算核。
- 基础经验默认3/6点；全卡仍为旧表13.688/29.936，所有相关结果明确期望、待核、非保底，不给成功概率。
- 当前档经验支持最多3位小数。当前已满级、同档或更低目标、阶段进度已满，均可产生0需求。
- 金币是购买预算；普通/军官包库存先免费使用，仅不足部分按100/330计费。不修改输入资产。
- 用户显式填写的固定本次销毁量按24/8/2.4/0.8计入；新版不管理卡牌库存、不自动选择销毁、不继承锁定。
- 自动“省金币”：可达时依次最少新金币、最少总包、最少溢出；“少开包”：最少总包、最少新金币、最少溢出。完全同分以普通包更少作稳定排序。
- 不可达时，在预算内最大化收益，再最少花费、最少总包。只优化两类包，固定销毁始终为用户给定项。
- 达标最低新购金币另行以充足预算、固定省金币排序求解；还缺金币为最低新购减当前金币、最低取0。手动草稿及当前推荐策略不改变该口径。全卡结果仍仅为期望估算。
- 所有经验按1000缩放为整数。目标至多200点，普通枚举上限67、军官34，不按库存或金币规模循环；超过各自单包型补足上限的组合会被更少包的可达组合支配。
- 为确保整数计算精度，V1技术输入上限为每种数量10亿、金币1万亿，不是游戏资产上限。空白、负数、小数资源、越界或非有限值拒绝计算；不会静默向下取整。
- 手动草稿与自动推荐分开保存；只有“采用推荐”明确替换手动草稿。超预算展示差额和不可执行，不假装可行。
- 基本输入通过本地存储保存；损坏/禁用显示警告并仍可计算，清空确认后恢复默认。仅本机存储，无游戏或账号连接。
- 可运行验证为Node内置测试及Playwright调用本机Edge，不安装浏览器引擎。测试结果不替代计划官独立验收。
